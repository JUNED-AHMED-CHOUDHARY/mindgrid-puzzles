# MindGrid Daily Interactive Logic Puzzles (PWA)

Play daily brain workouts, Calcudoku (Math Cages), and Futoshiki puzzles directly in your browser. Installable as an offline Progressive Web App (PWA).

## Features
- **Daily Rotation**: 7 unique curated logic puzzles across Calcudoku and Futoshiki.
- **Offline Capable**: Fully functional offline via Service Worker caching.
- **Large Print & Senior-Friendly**: High contrast, crisp grids, and accessible controls.
- **Instant Validation**: Check your solutions and track your completion time.
